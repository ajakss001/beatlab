# BEATLAB

Битмейкер прямо в браузере и комнаты для онлайн рэп-баттлов: 1 на 1 и 2 на 2, 3 раунда, 5 минут на бит, 75 секунд читки, жюри.

- Запуск у себя: `npm start` (или «Запустить BEATLAB.bat»), потом открыть http://localhost:5173
- Хостинг: Render, настройки в `render.yaml`
- План работ: `ROADMAP.md`
